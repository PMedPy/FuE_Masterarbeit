# Topic

Varianz ist der Fehler eines Modells und wird durch das Rauschen der Trainingsdaten verursacht. Das geschieht, wenn das Polynom zu viele Freiheitsgrade hat, und die [[Weight]] zu stark auf das Rauschen der Trainingsdaten trainiert wurden. Für jeden Datensatz sieht das Modell bei hoher Varianz anders aus. (Andere Fitting-Curve)
Heißt: Das Modell nimmt das Rauschen zu ernst.
Oder: Varianz kommt auf, wenn das Modell zu sensibel für den Trainingsdatensatz ist. 

Varianz: Das Modell ist zu Flexibel
Im Gegenzug zum [[Bias]], wo das Modell zu Starr ist, nie die Daten auch bei unendlicher Datenmenge repräsentieren kann.
