# Medical Device Regulation
Das neue **Gesetz** zur Zulassung von Medizinprodukten

Tests von Biomaterialien was die Biokompabilität angeht. 

Neue Punkte gegenüber der alten Zulassung: 
- Verschärfte Anforderungen
	- Strengere Vorgaben
- Vigilanzpflicht
- Vermeidung von Tierversuchen
- Fokus auf Test für Extractables und Leachables. 

Neuer Fokus, weg von Testorientierten Prinzip -> Hin zu Risikomanagement mit Produktlebenszyklus. 

[[ATMPs]] werden durch ein Extragesetz reguliert
