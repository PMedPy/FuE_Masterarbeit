# Aus Bayesischer Sichtweise

Maximum Likelihood (ML), also das optimierte Anfitten an Daten kann aus Bayesischer perspektive als Posterior mit Prior $p(\mu)=1$ gesehen werden. 

Das bedeute nicht, dass es einen Prior gibt bei ML. Es gibt gar keinen. 

> Vor einer Untersuchung wird jedes Ereignis ==a priori== als gleichwahrscheinlich gesehen. Das ist keine objektive Sicht, sondern eine spezifische Annahme über die Realität, die meist nicht greift.
