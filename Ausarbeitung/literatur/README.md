# Literatur

`literatur.bib` wird von **Zotero + Better BibTeX** hierher exportiert.

Einrichtung in Zotero:
1. Sammlung der Masterarbeit rechtsklicken -> *Export Collection*
2. Format **Better BibTeX**, Haken bei **Keep updated** setzen
3. Als `literatur.bib` in diesem Ordner speichern

Dadurch aktualisiert Zotero die Datei bei jeder Aenderung automatisch.
Zitiert wird mit dem BBT-Citation-Key, z. B. `\cite{torres2025generative}`.
